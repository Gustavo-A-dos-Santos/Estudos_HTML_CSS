Bem vindo! a Pagina Principal

Estamos aprendendo a utilizar o CSS para deixar nossas páginas HTML mais organizadas, bonitas e agradáveis para os usuários. Com ele, podemos modificar cores, fontes, tamanhos, espaçamentos e o posicionamento dos elementos.

Durante as aulas, estamos conhecendo diferentes propriedades do CSS e aprendendo como utilizá-las para personalizar cada parte da página. Também estamos entendendo a importância dos seletores, classes e identificadores na estilização dos elementos.

Com esses conhecimentos, estamos começando a desenvolver páginas com uma aparência mais profissional e aprendendo como o HTML e o CSS trabalham juntos para criar uma boa estrutura e apresentação para os sites.
